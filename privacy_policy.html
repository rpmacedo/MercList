Política de Privacidade - MercList

Última atualização: 09/11/2026

O aplicativo MercList ("nós", "nosso") respeita a sua privacidade. Esta Política descreve como tratamos as informações quando você usa o app.

1. Dados coletados

O MercList não exige cadastro nem login. Não coletamos nome, e-mail, telefone ou qualquer dado pessoal identificável.

  • Dados armazenados localmente: sua lista de compras, histórico de compras e cache de produtos são salvos apenas no seu dispositivo (SharedPreferences e SQLite). Não enviamos esses dados para nossos servidores.
  • Câmera: usada exclusivamente para escanear códigos de barras e etiquetas de balança. As imagens não são armazenadas nem transmitidas.
  • Internet: usada para buscar nomes de produtos na API pública OpenFoodFacts (enviando apenas o código de barras) e para exibir anúncios.

2. Anúncios (Google AdMob)

O app exibe anúncios fornecidos pelo Google AdMob. O Google pode coletar informações do dispositivo (identificador de publicidade, tipo de dispositivo, sistema operacional) para personalizar anúncios. Consulte a Política de Privacidade do Google para mais detalhes.

Você pode desativar a personalização de anúncios nas configurações do seu dispositivo (Android: Configurações → Google → Anúncios → Desativar personalização).

3. Compras in-app (Premium)

O app oferece uma compra única ("Premium") processada pelo Google Play. Não armazenamos dados de pagamento. O status Premium é salvo localmente no dispositivo.

4. Compartilhamento de dados

Não vendemos nem compartilhamos seus dados pessoais. Os únicos compartilhamentos ocorrem com:

  • Google AdMob (anúncios)
  • Google Play (processamento de pagamento)
  • OpenFoodFacts (consulta de código de barras)

5. Segurança

Os dados ficam armazenados localmente no seu dispositivo. Recomendamos manter o sistema operacional atualizado e proteger o dispositivo com senha/biometria.

6. Crianças

O app não é direcionado a crianças menores de 13 anos e não coleta dados de crianças intencionalmente.

7. Alterações nesta política

Podemos atualizar esta Política periodicamente. A data da última atualização será indicada no topo desta página.
